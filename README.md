# Farlight

Animated, narrated episodes about space, guided by a small alien called Orbi.

- Four episodes, from the Big Bang to our place in the galaxy, with studio narration and music
- A planet guide, a gravity sandbox, a quiz, interesting facts that play as animations
- A question box where Orbi answers with an animation
- Levels, badges, a day streak and a "what you learned today" recap

Everything is in `index.html` plus the narration recordings in `audio/`. Open it in a browser, or visit the live site once GitHub Pages is turned on:
https://ssgfhsap-lab.github.io/THE-SPACE-GAME/
